# Human-in-the-Loop Quantitative Trading System

An independent project investigating the automation of a discretionary
market-structure trading strategy.

## Current approach

Human:
- Identifies structural volume and price thresholds each week
- Determines important market structure

Computer:
- Monitors selected levels
- Detects predefined price behaviour
- Executes trades according to defined rules
- Manages risk
- Records trading data
